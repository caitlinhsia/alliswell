# allisw3ll

A cozy, all-in-one wellness notebook: scheduling, studying, journaling, and freeform sticky notes, styled like a modern paper notepad.

## Pages

- **Home (the desk)** — pick which notebook pages are "open" at once, side by side, like sheets on a desk.
- **Schedule** — a weekly planner for tasks and events.
- **Study** — subjects, a focus timer, session log, and per-subject to-dos.
- **Journal** — a lined notebook page per day with mood tracking and writing prompts.
- **Sticky Notes** — a freeform corkboard where notes can be dropped and dragged anywhere.

All data is stored locally in your browser (no account or backend required).

## Development

```bash
npm install
npm run dev
```
